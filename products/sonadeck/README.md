# SonaDeck

**为 Mac 集中管理应用音量和输出设备，保存多套音频配置，并在主界面一键切换。**

更新日期：2026-09-23。阶段：首期规划完成，M1 跨平台领域基础已开始；M0 音频原型与 Mac 真机验证尚未执行。

## 已确认的目标

- 名称：SonaDeck。
- 参考 SoundSource 的应用音量、设备与路由控制用途。
- 保存多套配置，在主界面直接切换整套配置。
- 重视 Mac 原生体验、系统版本兼容、响应速度与动画流畅度。
- 先完成以上闭环，扩展功能和 AI 留到后续规划。

首期以应用音量、静音、单应用输出选择和配置切换为核心。SoundSource 的完整效果器、AirPlay、多设备同步播放等能力不自动纳入本期；具体边界见需求。这是可调整的首期拆分方案，不是用户已经放弃其他功能。

## 当前技术建议

- 原生 Swift + SwiftUI，必要时用 AppKit；优先验证 Core Audio process taps。
- 最低系统暂定 macOS 15；首期先支持 Apple Silicon。两者是规划默认，待技术验证和目标用户反馈后冻结。
- 测试覆盖 macOS 15、26、27 对应的可用正式版本；完整版本与 build 在执行时记录。
- 同时评估沙盒与直接分发的技术可行性，尚未承诺上架 App Store。

## 已开始的开发

`app/ProfileDomain/` 是 Swift Package，已实现每应用规则的校验和切换前计划：缺设备或权限时阻断、旧配置独有规则释放、未运行应用待生效、相同状态下重复切换不产生操作。它尚不控制系统音频，也不含完整配置存储或 UI。运行与测试命令见[开发与测试](docs/development.md)。

## 下一步

执行 [M0 技术验证](docs/roadmap.md)：在 Mac 上验证“两个应用分别调音量、分别路由到两个输出、再切换两套配置”的最短闭环，以及故障后正常发声的恢复方式。

当前 Windows 环境可运行 Swift 领域测试；Xcode 构建、音频效果、设备兼容和流畅度尚未验证。Docker 结果不代替 Mac 验收。

SonaDeck 已被选为项目名；商标、域名和商店重名检查尚未完成，安排在公开发布前。保存配置并非已证实的独占功能，竞争价值需要通过真实切换任务验证。
