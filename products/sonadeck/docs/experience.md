# Mac 界面与体验规划

更新日期：2026-09-23。状态：设计方向和验收目标；没有最终视觉稿或已实现界面。

## 1. 设计方向

采用原生 Mac 工具的紧凑与清晰：系统字体、标准窗口工具栏、语义色、系统控件、可读的层级。避免把移动端大卡片布局搬到桌面，也不复制 SoundSource 的品牌和布局。

以 SwiftUI 原生组件为基础；菜单栏、窗口行为或焦点管理确有需要时补充 AppKit。新版系统材质随系统能力适配，不手绘仿制最新视觉效果；低版本保持完整操作能力。装饰不能降低文字、滑杆和当前状态的可读性。

## 2. 主窗口信息布局

以下仅表示信息关系，不是最终像素尺寸。初始尺寸建议约 780 × 560 pt，最小约 640 × 440 pt，原型阶段依据实际内容调整。

```text
┌ SonaDeck ─────────────────────────────── 设置 ┐
│ 配置  [工作 ✓] [会议] [音乐] [夜间]  [全部 ▾] │
│ 当前：工作 · 已修改       [恢复] [保存 ▾]     │
├─────────────────────────────────────────────┤
│ 系统输出  [USB DAC ▾]       音量 ───── 60%    │
│ 系统输入  [内置麦克风 ▾]    （可选管理）      │
├ 应用 ───────────────────────────── [添加] ──┤
│ Music    [静音] ───── 70%   [USB DAC ▾]       │
│ Safari   [静音] ───── 25%   [跟随系统 ▾]      │
│ Zoom     [静音] ───── 80%   [耳机 ▾] 待发声   │
├─────────────────────────────────────────────┤
│ 工作中的 3 个应用 / 1 项待生效               │
└─────────────────────────────────────────────┘
```

- 配置区固定在主界面顶部，常用前 4–6 套直接可点；其余通过“全部”访问，列表支持键盘定位。
- 点击配置名称即应用，不先进入详情页再点确认。设备缺失等阻塞结果在同一窗口解释。
- 应用行保持稳定排序，活跃音频变化不让整行跳动；首次新增可轻微淡入。
- 应用音量与设备硬件音量分区标识，避免误以为两个滑杆含义相同。
- 路由选择显示真实设备名和类型；重名时补充可区分的信息；不支持的设备说明原因。
- 不把实时波形当作首期必需装饰；若加入电平提示，只为帮助确认应用是否有声，并控制刷新成本。

## 3. 菜单栏和窗口行为

菜单栏图标提供当前配置、异常状态、常用配置列表、打开主窗口、设置和退出。主窗口与菜单栏使用同一状态源，不能分别维护音频控制。

首期建议保留 Dock 图标，使新用户容易找回窗口；关闭窗口继续工作，首次关闭给予轻量说明，不反复弹窗。支持标准窗口移动、缩放、多显示器和系统窗口管理。

标准键盘行为：Tab / Shift-Tab 焦点移动，方向键调整控件，Enter / Space 激活，Esc 关闭浮层，Command-comma 打开设置，Command-W 关闭窗口，Command-Q 退出。全局热键本期不实现。

## 4. 三条核心流程

**首次使用**：说明用途 → 展示权限用途及本地处理方式 → 用户主动启用音频控制 → 系统授权 → 看到真实应用与设备 → 调整并保存第一套配置。拒绝后提供重试和系统设置指引，不循环弹授权。

**日常切换**：点“会议” → 立即显示操作已接受 → 音频引擎执行 → 按实际结果显示已应用、待发声或失败。不能先把成功动画播完再执行，也不能无论结果都显示绿色勾。

**保存调整**：修改滑杆 → 显示“已修改” → 保存 / 另存为。切换其他配置时保留可恢复草稿，行为遵循 [配置语义](profiles.md)，不让保存对话框破坏快速切换。

## 5. 动画与响应预算

以下数字是产品初始目标，不是 Apple 强制标准或已经测得的数据。

| 交互 | 初始目标 | 原则 |
| --- | --- | --- |
| 点击反馈 | 100 ms 内出现选中 / 处理中反馈 | 反馈与音频完成分开，不假报成功 |
| 弹层和轻量展开 | 约 120–180 ms | 易打断；新操作取消过期动画 |
| 配置状态转换 | 约 160–220 ms | 克制的淡入与位置变化，不移动整张应用列表 |
| 滑杆拖动 | 输入立即反馈，音频参数连续平滑提交 | 不叠加追赶手指的弹簧动画 |
| 长操作提示 | 超过约 300 ms 才显示明显忙碌指示 | 避免极短任务闪烁 spinner |
| UI 帧预算 | 60 Hz 场景多数帧在 16.7 ms 内；120 Hz 设备单独实测 | 用 Instruments 检查拖动和连续切换的主线程阻塞 |

UI 过渡与音频增益斜坡是两件事。音频斜坡在音频路径中实现并独立测量，不能依赖 SwiftUI 动画时钟。

减少动态效果开启时，取消非必要位移、缩放和弹簧，保留简单状态替换或短淡变；所有信息仍可获取。依据 Apple 的[减少动态效果评估标准](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)进行检查。

## 6. 可访问性与本地化

- VoiceOver 可读出应用名称、当前音量、静音、输出和配置状态；切换结果有合适的通知，不持续播报高频电平变化。
- 全流程可仅用键盘完成；焦点明确，弹层关闭后回到触发控件。
- 错误和选中状态不只依赖颜色。支持深浅色、增加对比度、减少透明度与减少动态效果。
- 英文与简体中文从第一版布局开始覆盖，预留长设备名和长译文空间；不把字符串拼接写死在界面里。
- 滑杆提供可读数值及键盘精调；细小图标有足够点击区域和工具提示。

## 7. 必须设计的非理想状态

无有声应用、无配置、权限未授权、设备列表为空、目标设备离线、配置写入失败、切换部分失败、恢复失败、应用暂不支持、应用列表很多、长名称截断。

错误提示说明“发生什么、哪些设置没变 / 已变、下一步能做什么”。在主窗口内保留重要状态，不能只闪过一个 toast。设置页面不暴露 tap、聚合设备等实现术语，诊断详情可以按需查看。
