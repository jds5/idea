# Dayward 可交互预览原型

更新日期：2026-09-30。状态：本地浏览器原型，可在 Chrome 桌面及窄屏预览。Dayward 是本轮视觉工作名，尚未确认正式品牌。页面采用英语，原型控制面板附中文说明。

## 打开预览

在本目录执行：

```powershell
node server.cjs
```

然后用 Chrome 打开 [本地预览](http://127.0.0.1:4173)。只监听本机回环地址，不对局域网或公网发布。需要 Node.js；本轮实际使用 v24.12.0。无第三方 npm 依赖，不需要安装包或构建。

也可以直接在 Chrome 打开本目录的 [index.html](index.html)。使用经典脚本与本地图片，不需要在线字体或图片 CDN；本地文件模式的存储行为可能受浏览器设置影响，建议使用上面的 HTTP 入口。

端口被占用时先检查已有预览，不要结束其他进程。可在新终端设置独立端口：

```powershell
$env:DAYWARD_PORT = '4174'
node server.cjs
```

此时打开 `http://127.0.0.1:4174`；不同端口是不同存储来源。前台运行时用 Ctrl+C 停止。本轮预览已通过隐藏的 Node 进程启动，不需要额外 Docker 容器。

## 建议体验顺序

1. **Weather**：查看 Brighton 示例、切换日期和 °C/°F，点击 Why this window 查看分歧和阈值。切换到 Lewes 看一致情境、Eastbourne 看缺失情境。保存一个计划。
2. **Plan**：选择日期、活动和时长，点击 Try planning free 完成首次试用。三个地点显示一致、分歧和未知；List / Map 可切换，自定义风阈值会改变比较结论。
3. **Weekly outlook**：切换周，查看趋势与“不足以判断哪地更好”的解释；保存一周的关注记录。
4. **Saved**：复查保存时与当前模拟状态。右上角 Settings & preview 开启 Changed weather 后，Brighton 的风情境会发生变化。
5. **广告演示**：在 Settings & preview 选择 Demo returning visitor，再从规划页 Unlock planning。5 秒模拟完成后获得 24 小时本地权限；中途取消不获奖，基础天气仍可用。
6. **失败场景**：控制面板可演示 No ad available（赠送权益）、Weekly data unavailable（不提供该功能的广告入口）、Offline mode（阻止新解锁/调整比较）。Expire access 保留已保存计划。

控制面板的状态切换只改变访问情境，不删除已有计划。可以在 Saved 删除自己不需要的示例计划。首次试用、奖励和保存内容通过 `localStorage` 保存；刷新或重开同一浏览器来源可恢复。禁用存储时降级为当前标签页会话。

## 已实现与边界

| 内容 | 本轮实现 |
| --- | --- |
| 视觉 | 独立标识、本地原创 SVG 海岸插画、天气曲线、浅/深色、桌面侧栏/手机底部导航 |
| 页面 | 天气、模型解释、地点搜索、三地比较、示意地图、周趋势、奖励对话框、保存与变化、演示设置 |
| 交互 | 场景选择、阈值调整、首次试用、广告完成/取消、无库存赠送、过期、保存恢复、断网模拟 |
| 规则 | 少于两个完整模型为未知；分歧不能当概率；全部支持才符合；奖励幂等；保存原始偏好 |
| 无障碍基础 | 语义按钮/标题、原生对话框、焦点样式、跳过导航、小时文本表、减少动画媒体查询 |

这不是实时天气应用或 Android 工程。全部气象值、模型输入、周趋势与地理示意均为人为构造；模型名称仅用来演示界面，不代表取到了这些模型的数据。固定示例日期为 2026-09-30 起的几个日期及若干完整周；不是未来天气查询服务。

没有实际广告 SDK/SSV、付费、分析追踪、定位、推送、官方预警、商业天气 API 或云同步。时间轴仅提供五个示例日期，地点固定三个；没有落实设计中的全部 16 天详情、全偏好字段、组件、导出分享或全量异常矩阵。地图不能导航，不是气象栅格场；插画不是卫星图片。

奖励在本机模拟，无法抵抗篡改设备时钟或浏览器存储，不可用于生产授权。刷新恢复仅证明本地 UI 状态恢复，不证明真实广告回调、服务端补偿和交易校验可用。
