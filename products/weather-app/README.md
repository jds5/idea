# Weather App 产品设计

更新日期：2026-09-30。阶段：产品设计与 Chrome 交互原型已完成首版，尚未创建 Android 应用。

最新范围：用户明确面向欧美，要求重新评估广告、买断和订阅，并优先调查持续成本、可商用免费替代及个人开发者实际部署能力。现有广告原型保留为待验证方案；订阅尚未确认。首期不以部署超大参数模型为方案，成本与来源的新证据见[专项报告](docs/cost-and-free-alternatives-2026-09-30.md)。

用户已确认：以红色 Windy.com 为参照，不服务大陆地区，面向免费竞品方向，设计适合广告解锁的天气 App；最重要的是回答用户为什么选择我们。用户已进一步要求可在 Chrome 预览的原型。`weather-app` 是目录名，Dayward 是原型视觉工作名，均非已确认的正式品牌。

设计定位：帮助普通户外休闲和短途旅行用户选时间、选地点，并跟踪已经保存的计划。日常天气与单地点基本决策免费；自愿广告解锁完整规划工作区。这个选择理由是待验证的提案，不宣称已有市场优势。

规划默认：Android、英语、以英国用户作为首轮研究样本；短期详情与远期周趋势分开；首次试用后以广告取得规划权限。具体首发国家、品牌、技术版本、权益参数与数据采购均不是用户已经确认的最终决定。

## 当前状态与下一步

已验证：公开 API 可返回中期预报、EC46 集合成员及周距平；这仅证明获取数据可行，未验证预报准确率。

新增已验证：MET Norway / NWS 免费来源可返回目标市场样本，但有字段缺口；本地 Open-Meteo 自托管小实验可返回三模型短期和 EC46 周距平，无付费 API、无 GPU。冷读延迟、空值、缓存权限修复及证据边界见[实验记录](experiments/free-sources.md)，不代表生产选型完成。

已验证：海外已有多种免费替代品，地图重点对照 Ventusky、Zoom Earth、Flowx；VeriSky 已提供免费多模型比较与评分；Shadow Weather 官方条款记录了广告换 Premium。产品能力核验不代表准确率、留存或盈利验证。

设计已覆盖：用户理由→任务→页面→免费/广告权限→预报语义→可交付数据→验证。没有用“免费”“更多天数”单独充当差异点；专业气象全图层延后。

下一项可执行工作：先按[成本报告](docs/cost-and-free-alternatives-2026-09-30.md)验证免费商用来源与按需自托管的字段、连续可用性和真实资源开销，再比较托管报价。现有模拟原型仍可开展用户任务比较。尚未招募用户或发送任何外部消息。

验证结果：原型完成 7 项领域测试、Chrome 主要交互与桌面/窄屏视觉检查。既有数据实验仍只证明获取可行。原型天气和广告均为模拟，不存在已通过的用户选择、准确度、广告收入或 Android 真机体验结果。

尚未解决：用户是否比免费竞品更愿意使用本方案；周趋势在目标地区是否有决策增益；广告是否覆盖全部服务成本；供应商和预警授权；首发支持国家；Android 性能与辅助功能。红色 Windy 所谓 30 天页面仍未证实，但本产品不再以这个前提定义能力。

延后：完整地图气象平台、自建全球数据管道、自研天气模型、专业航海航空、多平台、订阅和上线发布。详细首期范围以产品需求为准。
