# Weather App 数据源研究

更新日期：2026-09-28。阶段：研究与小型数据可行性实验；尚未创建 Android 应用。

用户已确认的方向：开发天气预报 App，参考成熟 Android 产品 Windy，先深入调查约一个月预报的来源与接入方式。产品正式名称、首发平台、目标市场、付费方式及首期功能尚未确认；`weather-app` 只是目录名。

## 当前结论与下一步

已验证：公开 API 可返回中期预报、EC46 集合成员及周距平；这仅证明获取数据可行，未验证预报准确率。

规划默认：原型先采用短期预报与远期趋势分开的展示方式。建议从 Open-Meteo 开始；中国市场同时评估彩云企业次季节接口。建议不是已确认的采购或实现决定。

下一项可执行工作：选定目标地区和用户任务，按报告中的验证方案保存不同起报日的数据，并对候选商业供应商核实套餐、原始模型、再展示和缓存权限。取得商业接口凭证后再做同地点比较。

尚未验证：用户所指 Windy 的具体应用与 30 天页面；商业接口的实测质量；中国网络下的稳定性；模型在目标城市第 3–6 周的技巧；Android 地图、动画、耗电和无障碍体验。

延后：完整地图气象平台、自建全球数据管道、训练天气模型、上线发布。
