# Weather App 海外竞品与数据源研究

更新日期：2026-09-28。阶段：研究与小型数据可行性实验；尚未创建 Android 应用。

用户已确认的方向：以红色 Windy.com 为参照，开发不服务大陆地区的免费天气 App；当前先调查同类竞品，并保留约一个月天气趋势的数据可行性研究。`weather-app` 只是目录名。

尚未确认：正式名称、具体首发国家、首发平台、免费功能边界及首期用户任务。用户提出过“看广告解锁远期预报”，但最终变现机制尚未选定；免费也不自动等于无广告或所有功能无条件开放。

## 当前结论与下一步

已验证：公开 API 可返回中期预报、EC46 集合成员及周距平；这仅证明获取数据可行，未验证预报准确率。

已验证：海外已有多种免费替代品，地图重点对照 Ventusky、Zoom Earth、Flowx；VeriSky 已提供免费多模型比较与评分；Shadow Weather 官方条款记录了广告换 Premium。产品能力核验不代表准确率、留存或盈利验证。

规划默认：短期详情与远期趋势分开展示；Open-Meteo 仍作为数据实验候选。建议不是已确认的采购或实现决定。大陆市场供应商比较保留在历史报告中，不属于当前服务范围。

下一项可执行工作：按竞品报告中的相同任务，对 Windy 免费版、Ventusky、Flowx、VeriSky、Shadow Weather 做 Android 实际体验比较，确认免费边界和广告流程；随后选定首发国家与具体用户任务，再进行数据质量及成本验证。

研究路线：竞品扫描（已完成本轮）→ 竞品实测与任务选择（待做）→ 数据许可、准确度与广告经济性验证（待做）→ 确定首期范围后再进入原型实现。

尚未验证：红色 Windy 的所谓 30 天页面；商业接口质量与授权；模型在目标地区第 3–6 周的预测技巧；竞品当前 Android 广告解锁细节；广告收入能否覆盖数据和地图成本；Android 地图、动画、耗电和无障碍体验。

延后：完整地图气象平台、自建全球数据管道、训练天气模型、上线发布。
