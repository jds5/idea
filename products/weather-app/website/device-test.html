第一次真机测试。

本页面由电脑上的 Docker 服务提供。手机能打开此页面，说明当前浏览器已经连通服务；还需在 App 中完成连接验证。

1. 安装测试版

Android 9 或以上。下载后按系统提示，允许当前浏览器安装这一个测试包。

这是内部 Debug 包，非商店发布版。覆盖安装保留计划；卸载或清除应用数据会删除计划。

2. 确认连接地址

首次安装的 APK 已预填地址。若以前安装过旧版，在 Setup → Gateway origin 粘贴上面的地址，再点 Connect gateway。已有设置优先保留。

手机与电脑保持同一 Wi-Fi，测试期间保持电脑和 Docker 运行。手机上不要填 localhost、127.0.0.1 或 10.0.2.2。

    这里的时间是采集时间，不是模型起报时间；“缓存可用”不表示天气预测已验证准确。后台约每小时采集一次。

    4. 完成测试闭环

    1. Weather 选择 London，点 Load collected forecast。
    2. 选择未来时段和时长，点 Inspect this window，再命名并保存。
    3. 打开 Plans，查看保存的预测，点击 Check against latest collection。
    4. 彻底关闭 App 后重新打开，确认计划仍在；暂时断开 Wi-Fi，确认仍可查看保存基线，刷新时明确报错。
    5. 恢复 Wi-Fi 后再次复查；需要时删除测试计划。

    当前显示 Reference only / information incomplete 是预期行为：模型起报和原生小时溯源未完成，自动推荐与官方预警未接入。同一轮数据应提示 No newer collected snapshot。

    遇到问题时

    • 页面打不开：核对同一 Wi-Fi、电脑 IP、防火墙规则；访客网络、热点客户端隔离或 VPN 可能阻断设备互访。
    • 页面能开但 App 连不上：检查 Setup 的地址与端口，确认使用本页下载的 Debug 包。
    • 安装冲突：先记录现有计划；不要直接卸载来排错，先核对旧包签名。
    • 天气显示 unavailable/stale：等待采集完成，在电脑上查看 collector 日志。

    反馈时记录手机型号、Android 版本、操作步骤和错误原文。需要截图时可遮挡私人计划名称。
