# QR Lens（暂定名称）

更新日期：2026-10-07。阶段：首期实现与自动化验证；未发布 Chrome Web Store。

点击扩展图标，在当前网页可见画面上逐个解析二维码，显示原始字符串。拖动遮罩空白处框选后，仅保留完整位于选区内的二维码。截图和解码均在本地进行，不上传、不保存识别历史，不自动打开二维码中的链接。

## 安装与使用

开发环境：Node.js 22、npm。目标浏览器：Chrome 109+（最低版本尚待真机验收）。

```powershell
cd products/qr-lens
npm ci
npm run build
```

1. 在 Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 点击「加载已解压的扩展程序」，选择本目录的 `dist` 文件夹，并将 QR Lens 固定到工具栏。
3. 打开有二维码的普通网页，点击扩展图标，等待本地解析。
4. 在遮罩空白处拖动，框住完整二维码；「显示全部」清除筛选。
5. 点击「复制字符串」，或在结果文本框中选中文字后按 Ctrl/Cmd+C。结果面板的鼠标操作不会启动框选。
6. 若面板挡住二维码，点击「收起结果」后框选，再点击「显示结果」。支持「键盘框选」：方向键移动、Shift+方向键调整大小、Enter 确定、Esc 取消。
7. 按 Esc、点击「关闭」或再次点击扩展图标退出。窗口尺寸变化时自动退出，防止位置错配。

解析失败时会显示错误；无法注入的页面会在扩展图标显示 `!`，鼠标悬停可查看原因。
